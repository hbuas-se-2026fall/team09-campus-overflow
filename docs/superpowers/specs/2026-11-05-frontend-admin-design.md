# 管理后台前端设计

## 范围与依据

将已交付的前端工程及页面分包迁移到团队新仓库的功能分支，并新增可核查的管理员页面。新仓库 main `0983422` 与旧仓库共享历史；整合时保留团队后端重构。只推送功能分支，不合并 main。

当前 OpenAPI 没有管理员身份、用户管理、管理员关闭问题或后台统计接口。现有关闭接口只允许提问者操作，不能复用为管理员权限。协作规范允许前端先使用 mock 开发。此次不更改后端、不把演示操作描述成真实管理能力。

## 方案选择

采用独立开发演示模式：完成后台页面与交互，正式入口保持关闭，等待后端契约。只做静态原型无法验证操作；直接假设管理员接口会产生契约漂移；扩展后端 RBAC 超出本次前端任务。

## 页面与数据

- 开发模式通过 `pnpm run dev:admin` 启动，提供 `/admin/preview` 和明确的演示入口。
- 概览展示演示样本中的用户数、问题数、开放/关闭问题数、停用账号数及标签目录；不宣称是线上统计。
- 问题管理支持标题/作者/标签搜索、状态筛选、分页、查看详情和二次确认关闭。关闭后列表、详情与统计同步更新；不提供未经需求授权的删除。
- 用户管理支持邮箱/学工号搜索、角色与状态筛选、分页、查看资料、确认停用和恢复账号。
- 所有演示数据仅驻留页面内存，刷新或点击重置恢复初始样本；不调用业务写接口，不修改真实登录状态。
- 使用现有 Ant Design、React 状态及 CSS；不新增运行时依赖。后台组件与演示样本延迟加载。

## 权限与错误处理

- 正式 `/admin` 未登录跳转登录；登录后重新请求 `/auth/me`，不信任浏览器保存的角色，当前契约下显示无管理员权限和接口尚未开放的提示。
- 演示入口同时受 Vite 开发模式和专用 `admin-preview` mode 限制；普通启动及生产构建均不能显示或打开演示页面。演示模式无需真实管理员账号。
- 正式身份请求显示加载、错误和重试状态。演示列表具有空状态、搜索清除、操作确认及操作完成反馈。
- 手机端筛选栏自动换行，表格在容器内横向滚动。

## 验证

运行现有类型检查、lint、单元/契约测试、覆盖率门禁、生产构建及原有 E2E。新增浏览器用例核实演示搜索/筛选/详情/关闭、账号停用/恢复、重置、无真实写请求，以及正式入口对游客/普通用户/伪造本地管理员的拒绝。另在生产预览中验证演示入口不可访问，确认分包继续无 500KB 警告。

## 后端交接

待后端确认管理员身份的服务端来源及管理权限、统计口径、问题列表/管理员关闭、用户列表/停用恢复的 OpenAPI 后，再实现真实适配器和后端鉴权联调。本文中的演示数据结构属于前端视图模型，不是已存在或已约定的 API。
